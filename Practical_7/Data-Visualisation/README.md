# Data Visualization Dashboard

## Overview

This project is a React-based analytics dashboard developed using different charting libraries such as Recharts and Chart.js. The dashboard visualizes analytical data using multiple chart types including line charts, pie charts, bar charts, and area charts.

The project demonstrates how charting libraries can be integrated into React applications to create responsive and interactive data visualizations.

---

## Features

- Monthly Sales Line Chart
- Product Category Pie Chart
- Customer Acquisition Bar Chart
- Weekly Visitors Area Chart
- Responsive Dashboard Layout
- Interactive Data Visualization

---

## Technologies Used

- React.js
- Recharts
- Chart.js
- react-chartjs-2
- Vite
- JavaScript
- CSS

---

## Installation

Clone the repository:

```bash
git clone https://github.com/syangche/Data-Visualisation.git
```

Navigate to the project directory:

```bash
cd Data-Visualisation
```

Install dependencies:

```bash
npm install
```

Install chart libraries:

```bash
npm install recharts chart.js react-chartjs-2
```

Run the development server:

```bash
npm run dev
```

## Chart Components

### Monthly Sales Chart
A line chart created using Recharts to visualize monthly sales performance.

### Product Category Chart
A pie chart used to display product category distribution.

### Customer Acquisition Chart
A bar chart implemented using Chart.js to compare customer acquisition from different platforms.

### Weekly Visitors Chart
An area chart displaying visitor statistics throughout the week.
