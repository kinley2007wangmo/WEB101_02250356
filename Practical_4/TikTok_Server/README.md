# TikTok Server (Backend)

##  Project Overview

This is the backend server for the TikTok Clone project developed for WEB101. The server is built using Express.js and provides API endpoints for users and videos.

---

##  Features

- Express.js backend server
- REST API endpoints
- User API
- Video API
- JSON response handling
- CORS enabled for frontend communication

---

##  Technologies Used

- Node.js
- Express.js
- Nodemon
- CORS

---

##  Installation & Setup

### Install Dependencies

```bash id="v4h1wl"

```

### Run Development Server

